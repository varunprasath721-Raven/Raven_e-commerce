The Django seed command now creates 14 Jeans products using these images. The frontend local fallback also uses the same images.

Run backend:
  cd backend
  pip install -r requirements.txt
  python manage.py migrate
  python manage.py runserver

Run frontend in another terminal:
  cd frontend
  npm install
  npm run dev

Open: http://localhost:5173/shop?category=jeans
