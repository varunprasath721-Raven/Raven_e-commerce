After extracting:
1. Backend:
   cd backend
   pip install -r requirements.txt
   python manage.py migrate
   python manage.py seed_products
   python manage.py runserver

2. Frontend:
   cd frontend
   npm install
   npm run dev

If the browser has cached old products, clear localStorage or use a fresh browser session.
