RAVENMART - REAL MOBILE PRODUCT IMAGE VERSION

1) Backend
cd backend
venv\Scripts\activate
python manage.py migrate
python manage.py seed_products
python manage.py runserver

2) Frontend (new terminal)
cd frontend
npm install
npm run dev

3) Open the URL shown by Vite (5173 or 5174).
